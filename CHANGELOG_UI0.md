# V2-UI0 branch scope

This branch intentionally does **not** change production data, Life API behavior, meal behavior, or Legacy Game rules.

It only establishes the visual foundation needed before V2-P2:

- island-life design rules;
- `/ui-lab`;
- interactive Mood / Sleep / Activity prototypes using fake local state;
- Nest entry density prototype;
- upstream `animal-island-ui 1.8.x` compatibility research;
- open-source UI reuse mapping.

This branch also intentionally leaves `package-lock.json` on the current `animal-island-ui 1.0.1` until the compatibility and visual gates are complete.
