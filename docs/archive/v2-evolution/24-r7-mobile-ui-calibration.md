# R7：移动端 UI 校准

> 状态：R7 已于 2026-09-03 部署 Production；Git 自动部署已重新关闭，等待真实手机验收反馈。

## 1. 原因

R6 建立了视觉 token 和页面 adapter，但 Production 手机截图表明实际组件仍有卡片膨胀、信息密度过低、系统 emoji 混用、设计稿还原不足等问题。R7 以真实窄屏观感为准，不再把“接入 CSS”视为视觉完成。

## 2. 全局校准

- Life 主内容最大宽度由 `46rem` 收回到 `30rem`；
- 卡片基准圆角改为 `18px`，降低阴影和内边距；
- 底部导航使用统一线性 SVG 图标；
- 统一返回按钮、粘性工具栏、数据卡和空态材质；
- 页面副标题只保留对用户有用的简短说明。

## 3. 页面结果

- 今日：日期式标题；心情、睡眠、活动卡片压缩；活动场景使用两位女孩透明角色图。
- 饮食：餐卡和营养信息更紧凑；汇总卡降低体积；长列表启用延迟渲染。
- 餐食编辑：照片改为 `16:9`，元信息、照片、食物明细建立清楚层级。
- 日历：轻网格纸张；日期下方按“我在上、Ta 在下”展示最多两枚心情。
- 小窝：窗、天气、植物不再使用 emoji；房间场景使用 CSS 物件与透明人物图。
- 体重：当前数值、趋势、录入、历史记录统一为克制的数据层级。
- 小信箱：信纸边框与工具栏统一；减少普通 SaaS 卡片感。
- 家庭药箱：搜索、筛选和返回操作统一为高密度工具栏。
- 日期详情、游戏机、我的：统一返回、标题、卡片与说明层级。

## 4. 八种心情

固定为：

```text
心累 / 生气 / 兴奋 / 烦躁 / 心动 / 平静 / 伤心 / 开心
```

透明毛绒圆脸素材统一用于首页、选择器、月历、日期详情和 `/ui-lab`。新增稳定数据值 `excited`，通过独立 migration 扩展数据库约束；Production migration 已于 2026-09-03 执行并验证。

## 5. 验证与上线边界

代码完成后统一执行 Test / Lint / Build。本次在取得用户单次明确授权后完成 Production Supabase migration 与 Vercel Production 部署，随后立即恢复 `git.deploymentEnabled: false`。

## 6. 无感同步

页面数据通过进程内 stale cache 立即回显，并在后台重新验证；增删改会同步写回或失效对应 cache，避免页面切换时整块内容闪白。

## 7. R7 实机反馈修正

- 登录或退出后主动重新读取 session；账号身份发生变化时清空全部共享查询缓存，避免继续显示上一账号的“我 / Ta”。
- 登录跳转首页前并行预热今日、当月日历、双方餐食、双方体重、药箱和信箱数据，第一次进入子页不再出现整页刷新。
- 首页毛绒心情去除外围彩色圆框并增大；月历中的双人心情同步放大，保持上下排列和当天太阳标记。
- 小信箱重构为日期轴信纸列表，保留收信/寄信切换，并新增默认“全部信件”的月份归档筛选。
- 本批验证：Vitest 29 个文件、156 项测试通过，ESLint 通过，Next.js Production Build 通过。

- 所有会读取云端生活数据的界面统一采用 stale-while-revalidate：今日、饮食、月历、日期详情、体重、小信箱和家庭药箱；
- 页面再次进入时先显示内存缓存，缓存过期后在后台静默刷新，不再清空页面或插入会推动布局的同步提示；
- 日期详情的生活、双方饮食请求并行执行，并以日期和当前身份组成隔离缓存键；
- 体重、药箱和信箱写入成功后直接更新本地缓存，不再保存后整页重拉；
- 编辑餐食优先复用饮食列表中的完整记录，同时在后台核对最新数据；
- 无数据缓存的首次访问仍会等待真实接口，失败时保留已有缓存并展示轻量错误信息；登录失效仍遵守鉴权边界。
