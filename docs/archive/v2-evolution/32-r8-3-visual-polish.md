# R8.3 视觉语言与信息减法

## 背景

R8.2 解决了手机实机截图中最明显的结构问题，但继续复核后发现：部分控件仍然在“解释程序怎么工作”，而不是呈现生活本身；同时饮食缺少日汇总、药箱信息层级仍不够成熟。

R8.3 的原则：

```text
功能说明能从界面本身看懂 -> 删除解释文案
真正有生活氛围的句子         -> 保留
状态、安全或错误信息           -> 保留
```

例如：

```text
删除：8 小时为满环，时长一眼就能看见。
删除：固定餐次 · 一天一个入口。
删除：默认使用小叶子；点左侧图标……
删除：和首页同一套卡片……

保留：把普通日子里的小事，轻轻收好。
保留：普通的一天，也值得被记住。
保留：好好吃饭，也把喜欢的味道留下来。
```

## 首页

### 一起度过天数

不再单独把数字做成高饱和青绿色：

```text
一起度过的第 384 天 ♡
```

整行使用视觉语言里的柔和灰绿，数字只用字重强调；爱心使用低饱和粉色。

### 心情

- 我 / Ta 卡片完全同底色、同边框；
- 不再通过 `is-me` 背景选中态区分“我”；
- 心情名称和“我 / Ta”文字已经足够完成身份区分；
- 心情选择仍保持点选即关闭。

### 睡眠

- 两个人的睡眠圆环统一使用同一个 `--life-mint-strong`；
- 深浅差别不再承担身份语义；
- 8 小时仍为 100%，超过 8 小时封顶；
- 删除“8 小时为满环”等实现说明。

### 活动

保留活动插画中的温暖句子，删除顶部“今天一起做过的事”和 icon picker 使用教程。

## 饮食

### 编辑入口

已有餐食统一使用小型铅笔 SVG，不再显示“编辑这顿 / 编辑这次”；没有记录时才显示 `+ 添加早餐` 等文本动作。

### 当日汇总

新增共享组件：

```text
components/life/DailyNutritionSummary.tsx
```

展示：

- 当日总热量；
- 碳水克数与占比；
- 蛋白质克数与占比；
- 脂肪克数与占比；
- 三大营养素热量占比圆环。

占比按：

```text
碳水 4 kcal/g
蛋白质 4 kcal/g
脂肪 9 kcal/g
```

饮食主页底部和日历某日详情复用同一个组件。

从日历详情进入 `/food?date=YYYY-MM-DD` 时，饮食页现在会真正读取历史日期，不再自动回到今天。

## 日历日期详情

心情 / 睡眠 / 活动继续复用首页卡片。

饮食区升级为：

```text
我：当天吃了什么 + 当日营养汇总
Ta：当天吃了什么 + 当日营养汇总
```

而不是只有一段餐食文本和总 kcal。

## 家庭药箱

参考仍在活跃维护的开源 MedTimer 的信息优先级：库存、过期状态、筛选应该在第一视线。仅参考产品信息层级，不复制其 Android 代码或视觉资源。

R8.3 药箱：

- 顶部显示药品总数 / 需要留意数量；
- 搜索与添加压成紧凑工具栏；
- 状态筛选横向紧凑排列；
- 每个药品使用独立小卡；
- 左侧统一胶囊 SVG；
- 中间突出名称、状态、最终失效日、剩余天数；
- 右侧突出库存数量；
- 编辑 / 删除降级成小图标；
- 快过期 / 已过期使用低饱和状态边条，而不是大面积警告色。

## 游戏机

删除：

```text
开始游戏 →
```

可玩的卡片只在最右侧显示与小窝视觉语言一致的宽 `›`；同时删除“当前只接一个已有游戏”等开发说明。

## 小信箱

产品术语正式调整：

```text
letter   -> 手札
postcard -> 明信片
```

“手札”代表可以写标题和长正文的长内容；“明信片”代表短内容。

数据库枚举 `letter/postcard` 不改，只调整用户可见文案，避免无意义 migration。

## 我的

正式 UI 改为：

```text
我的
├─ 小猫 / 小鱼
├─ 云端同步：已连接
├─ 数据管理
└─ 退出当前账号
```

删除：

- `cat/fish` 技术标识；
- CURRENT ACCOUNT；
- 身份映射；
- 写入权限；
- 大段当前账号说明；
- “生活 AI 助手”入口。

### “生活 AI 助手”是什么

它是 R9 开发的程序内 `/ai` 备用入口，用于直接调用 canonical life agent registry。随着正式主入口确定为 ChatGPT Projects：

```text
Harbor Cat  / 团子
Harbor Fish / 仔仔
```

R9 `/ai` 继续保留为内部备用能力，但不再占据正式“我的”页面。

## 数据管理

保留真实能力：

- 立即备份；
- JSON 导出；
- JSON 导入；
- 恢复点；
- 恢复前保护点。

删除：

- 新版程序 / 旧程序关系说明；
- “去游戏机”入口；
- Supabase / Drive / 浏览器事实源的长篇技术说明。

这些架构内容继续留在开发文档，不放给日常用户看。

## 体重与餐食编辑说明清理

本轮同步移除：

- “同一天记录多次……日平均”页头说明；
- 趋势图下方重复解释日平均算法；
- “不再记录备注”等实现说明；
- 餐食编辑“和饮食列表使用同样构图”等实现说明。

数据行为本身不变。

## 部署纪律

R8.3 开发 / CI / PR 不等于 Vercel 部署。

```json
{
  "git": {
    "deploymentEnabled": false
  }
}
```

必须等用户再次明确授权才能部署 Production。
