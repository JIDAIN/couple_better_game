# R8.2 实机 UI 二次校准

## 背景

R8.1 已完成结构和主要交互收口，但 2026-09-03 Production 手机实机截图显示，部分页面仍与 `docs/12-island-life-design-system.md` 的人工确认视觉语言存在明显差距。本轮以实机截图为准继续校准，不把“结构已经对”误认为“视觉已经完成”。

## 本轮六项基线

### 1. 小信箱

结构继续保留：收到/寄出、信纸/明信片、月份筛选、等高预览、点开阅读全文。

视觉重新采用成熟日记产品常见的“纸张层级 + 克制元信息 + 阅读正文”模式：

- 工具栏降低 SaaS Dashboard 感；
- 预览从 11rem 压到约 9rem；
- 信纸标题和摘要改用中文衬线字体栈；
- 纸张主题只做低对比渐变/纸纹，不做大面积粗体装饰；
- 邮戳、日期、操作降级；
- 阅读层正文使用更舒适的行距。

参考公开项目仅借交互与信息层级，不复制第三方 GPL 代码：

- StoryPad：timeline journal、主题与阅读层级；
- Daily You：轻量日记、数据所有权、备份/恢复入口。

### 2. 数据管理

原“我的 → 数据管理”只是说明文字，虽然 R8 数据库已经有事务备份与恢复 RPC，但可见 UI 没有真正接入。本轮改成真实功能页 `/me/data`：

- 立即创建完整恢复点；
- 查看最近恢复点列表；
- 导出 `user + config` 完整 JSON；
- 导入完整 JSON；
- 从任一恢复点恢复；
- 恢复/导入前必须输入 `确认恢复生活数据`；
- 底层 `restore_life_backup_snapshot` 仍先自动创建 `pre_restore` 完整快照；
- 新增 `import_life_full_data`，兼容 R10 `get_life_full_export` 的 `user + config` 格式；
- 数据存放说明降到页面底部，不再把“去游戏机”当作数据管理本体。

旧游戏覆盖仍使用旧规则 `确认覆盖游戏数据`，与新版生活数据恢复严格分开。

### 3. 小窝

- 四入口取消系统 emoji 作为主图标；
- 改成同一线条语言的项目内 SVG：体重秤、信封、药箱、游戏手柄；
- tile 使用两列 Grid，为箭头单独预留列；
- 箭头不再 absolute 压在说明文字上；
- 卡片高度、圆角、图标容器、阴影重新按手机密度缩小；
- 纪念日也同步缩小并把爱心放在一起度过天数句末。

### 4. 首页操作按钮与一起度过天数

`AppButton`/组件库默认尺寸导致“编辑 / +记录”在实机上变成大圆框。本轮首页改用专用 `life-card-action`：

- 约 31px 高；
- 13px 圆角；
- 1px 轻描边；
- 不再占据卡片右上角大面积空间。

首页关系信息调整为：

```text
一起度过的第 384 天 ♡
```

数字为青绿强调，爱心在句末，整行层级低于日期标题。

### 5. 心情选择

- 去掉 mood choice 的背景圆、阴影和选中边框；
- 毛绒心情图本身放大；
- `aria-checked` 只保留无障碍语义，不生成视觉框；
- 点击心情即关闭 bottom sheet 并保存；
- 保存失败才重新打开 picker 并提示错误；
- 不需要二次确认。

### 6. 活动图标

固定横排“散步/学习/运动...”不是用户所说的补充图标。本轮改为 Notion 类交互：

```text
[默认图标] [自由文本输入……………………] [添加]
      ↓ 点击
  图标 Popover
```

- 默认 `🌱`；
- 点击左侧图标才展开图标面板；
- 面板提供 30 个活动相关 icon；
- 新增和编辑已有活动共用同一 icon picker；
- 活动本体仍是自由文本，而不是强制类别；
- 点“添加”仍立即进入列表。

## 部署纪律

本轮开发、PR、CI、Supabase migration 与文档更新不等于 Vercel 部署。

`vercel.json` 必须继续保持：

```json
{
  "git": {
    "deploymentEnabled": false
  }
}
```

R8.2 只有 Test / Lint / Build 全绿并合并 main 后，才等待用户下一次明确的 Production 部署许可。
