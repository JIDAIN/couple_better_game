# 热力图日期逻辑说明

## 当前实现

首页成长地图由 `components/home/DualMonthlyHeatmaps.tsx`、`PlayerHeatmap.tsx`、`HeatmapCell.tsx` 和 `mockHeatmapData.ts` 组成。

当前规则：

- 热力图按月查看，支持上个月 / 下个月切换。
- 每一行固定按周六到周五排列。
- 左侧不再显示“第 1 周 / 第 2 周”这类周次标签。
- 月视图会显示完整周。如果第一行或最后一行跨月，会显示上个月或下个月日期。
- 跨月日期不是空白占位，会按真实 `recordDate` 读取 `dailyRecords` 中的热力图数据。
- 跨月日期会弱化显示，方便区分是否属于当前查看月份。

## 日期落格

`buildMonthGridByStartDate()` 会：

1. 取当前查看月份的第一天和最后一天。
2. 找到第一天所在周的周六，作为网格起点。
3. 找到最后一天所在周的周六，作为最后一行起点。
4. 按自然日期连续生成完整周网格。
5. 通过 `recordDate` 读取当天鱼鱼 / 猫猫的 `HeatmapDay`。

例如 2026 年 5 月 1 日是周五，因此 2026 年 5 月热力图第一行会显示：

```text
2026-04-25, 2026-04-26, 2026-04-27, 2026-04-28, 2026-04-29, 2026-04-30, 2026-05-01
```

如果 `dailyRecords` 中有 `2026-04-30` 的记录，它会显示在 5 月视图第一行的 4/30 格子里。

## 作战开始日

首页的“作战开始日”表示记录起始日。只要保存的是合法 `YYYY-MM-DD`，界面会回显该日期，不会强制改回默认值。

`defaultHeatmapStartDate()` 只在没有合法日期时提供 fallback。它会取当前查看月份第一天所在周的周六。

## 周计算口径

热力图视觉行和金币 / CSV 周次使用同一个周六到周五口径，但职责不同：

- 热力图负责把日期摆到正确星期格里。
- 金币、周统计、CSV 周次负责计算业务周。

修改热力图展示不应改变金币规则。
