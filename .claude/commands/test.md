# Add Or Fix Tests

请根据用户描述补充或修复测试。

## 自动前置要求

开始前必须先阅读：

1. `AGENTS.md`
2. `CLAUDE.md`
3. `README.md`
4. `docs/testing-guide.md`
5. 与测试对象相关的源码和文档

## 工作方式

1. 先判断应该测什么行为
2. 优先写真实行为测试，而不是只测实现细节
3. 尽量放在 `tests/home/` 下已有相关测试文件中
4. 如果需要新增测试文件，说明原因
5. 不要为了测试暴露不必要的内部实现
6. 测试应保护业务规则、数据恢复、store、状态重算或关键交互

## 必须补测试的情况

如果改动涉及以下内容，必须补测试：

- 结算规则
- 金币规则
- 钱包计算
- 热力图等级
- 热力图日期逻辑
- `DailyRecord` 结构
- `ExchangeRecord` 结构
- snapshot 恢复逻辑
- store 逻辑
- 导入导出逻辑
- legacy 数据兼容逻辑

## 验证命令

优先运行或建议运行：

```bash
npm run test
```

必要时再运行：

```bash
npm run lint
npm run build
```

## 输出格式

完成后用中文输出：

1. 测试目标
2. 修改文件
3. 覆盖的场景
4. 验证方式
5. 是否已运行测试
6. 风险或未完成事项

$ARGUMENTS
