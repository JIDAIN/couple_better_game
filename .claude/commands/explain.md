# Explain Code

请解释用户指定的代码、文件、模块或机制，不要修改代码。

## 自动前置要求

开始前必须先阅读：

1. `AGENTS.md`
2. `CLAUDE.md`
3. `README.md`
4. 与问题相关的 `docs/` 文档和源码

如果 `AGENTS.md` 或 `CLAUDE.md` 不存在，请先提醒用户。

## 工作方式

只解释，不修改代码。

请根据用户问题说明：

1. 相关文件在哪里
2. 这段代码负责什么
3. 数据如何流动
4. 它和其他模块的关系
5. 哪些地方容易出 bug
6. 如果要修改，应该注意什么

## 输出要求

请用中文解释。

尽量使用：

- 简洁小标题
- 必要的代码片段
- 清楚的因果关系
- 项目当前真实结构

不要泛泛而谈。

## 用户输入

$ARGUMENTS
